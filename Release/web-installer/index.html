ATU Remote Display

Install the complete, tested firmware onto a 4 MB classic ESP32 DevKit.

Connect the ESP32 with a data USB cable, then select its serial port.

Requirements: A current desktop browser with Web Serial support, such as Chrome, Edge, or Firefox; a USB data cable; and a classic ESP32. Do not use this installer with ESP32-C3, S2, S3, or C6 boards.

If the board does not connect, hold its BOOT button while starting the install. Complete instructions are in INSTALL.md.
